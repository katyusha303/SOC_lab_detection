A DVWA(Damn Vulnerable Web App) is the target app we will be using to prove our SIEM setup. It is an app used by many researches in the field of cybersecurity to let you ethically 

run malicious attacks against it to strengthen your skills and knowledge. However in this project, it will be used to generate the logs we want to watch.

The DVWA is an app that is ran under the name of an XAMPP(Cross-platform, Apache, MariaDB, Perl, PHP) which is the complete package thats lets the DVWA initiate and run.

Lets clarify each term:

Cross\_platform: can be used on different OSs like Linux,windows,MacOS,etc.

Apache: It is the server responsible for receiving the user's requests. Runs on the HTTP port 80 protocol.

MariaDB: Database that is like an alternative to MYSQL.

Perl: Programming Langauge.

PHP: receives the user's data (GET/POST forms) from Apache, and decides on how to deal with it (sending it to backend or database).
