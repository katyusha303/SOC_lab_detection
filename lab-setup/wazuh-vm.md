Wazuh is an open-source SIEM(security information and event manager) that used by both students and companies offering security solutions.
It is a widely reputable and matches an excellent level with respect to the project we are performing.
The WAZUH SIEM is separated to two parts:

1.The WAZUH manager which is the part responsible for analyzing the traffic forwarded by the agent. For the purpose of our project, the ideal setup is for the manager to be

installed on a VM.

2.The WAZUH agent that is installed on the computer to be surveilled. Its role is to forward the logs to the manager to analyze them, and to show the information on the dashboard.

The dashboard is accessible by simply entering the IP address of the wazuh manager in any browser. The IP of the manager is known by entering "ip a" in the terminal of the manager,

supposing the wazuh VM's network settings are set to bridged network which allows it to have its own IP.

In this project , Wazuh will specifically be analyzing and showing the logs of the DVWA, which are generated by the Apache web service(it is part of the XAMPP that runs DVWA).
The windows manager is configured via a specific file in it, by adding certain instructions, to "watch" for the logs generated by Apache. As previously mentioned, those logs are

sent to the Manager.
